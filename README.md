# ChiHallu-Bench

A Multi-dimensional Hallucination Taxonomy and Benchmark for Chinese LLMs.

- **5,700** hallucination evaluation samples in `ChiHallu-bench_v1.0.json`
- 12 subcategories across 3 dimensions: factuality hallucination (FH), faithfulness hallucination (FaH), Chinese-specific hallucination (CH)
- 4 domains: encyclopedia / finance / government affairs / medical
- Difficulty: easy 1,710 / medium 2,565 / hard 1,425
- Adversarial 1,995 (35%) / non-adversarial 3,705 (65%)
